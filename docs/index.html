怎么读这 4 个百分位 & 出手规则（用法说明）

4 个百分位（都是近 5 年 percentile rank，0-100）：头部百分位条里的 MA200 占比 + 下方三张卡片的 上证综指 / 沪深300 / 创业板指。数值越低 = 越接近 5 年低位（越便宜 / 超卖）；越高 = 越接近 5 年高位（越贵 / 过热）。它们各自基于不同序列，彼此不可直接相减。

真正的「宽度 vs 指数」背离看三张背离子图里的 Spread = MA200 占比分位 − 该指数分位：背景 红（宽度领先） / 绿（指数领先），|Spread| ≥ 25 为大劈叉；|Spread| < 25 即宽度与指数收敛、结构健康。

出手规则：当某张子图 |Spread| < 25（收敛、无大劈叉） 且 对应指数百分位偏低（<30%，最好 <20%） 时，分批考虑入手；若出现「指数领涨、宽度滞后」的绿色大劈叉，是分化反弹，勿追。低位 ≠ 立刻反转，宜分批 + 以「宽度回升 / Spread 收敛」作右侧确认。下方「结果判断栏」已按四百分位组合给出综合结论。
